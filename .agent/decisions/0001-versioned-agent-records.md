# ADR-0001：使用版本化协作文档

- 日期：2026-09-02
- 状态：已接受
- 参与者：Codex、项目维护者

## 背景

课堂同步服务涉及 API、Docker 编排、数据库、对象存储、Jupyter 插件与前端代理。仅靠聊天记录难以追溯服务地址、接口兼容性和运行前提。

## 决策

在仓库内维护 `.agent`：状态、架构、接口契约、运行手册、开发规则、Git 流程、产品边界、交接记录和 ADR 模板均与代码版本一同管理。

## 影响

- 每次接口、代理或持久化语义变更都可追溯。
- 文档不存储凭据、真实学生数据或真实生产上游地址。
- Docker 构建上下文应排除 `.agent`。
