# 5 分钟课堂试运行脚本

只使用本目录的 `analyze_scores.py`，不要使用真实学生代码或真实 API Key。

## 0:00–1:00 准备

1. 新建空文件夹并复制 `analyze_scores.py`。
2. 用 VS Code 打开该文件夹并设为受信工作区。
3. 教师端发布一个方案：题目为“完善成绩分析函数的空列表处理”，观察依据为“先记录
   空列表失败运行，修改后记录成功运行”。
4. 切换学生端、确认范围并开始监控。

## 1:00–2:00 记录失败

运行扩展命令“运行当前 Python 文件并记录”。原文件调用空列表，应记录失败运行。

## 2:00–3:00 修改并成功

在函数开头增加：

```python
if not scores:
    return {"count": 0, "average": 0.0, "highest": None, "lowest": None, "pass_rate": 0.0}
```

保存，再次使用扩展命令运行，应记录成功运行。

## 3:00–4:00 验证恢复

关闭 VS Code 窗口，重新打开同一文件夹。出现恢复提示时选择“继续会话”。关闭期间不会
产生新事件，恢复只包含此前已经保存的数据。

## 4:00–5:00 结束和导出

点击“结束并生成简报”，然后运行“导出会话”。检查导出目录包含：

- `plan_snapshot.json`
- `operation_log.json`
- `process_log.md`
- `classroom_brief.json`
- `manifest.json`

打开 `classroom_brief.json`，确认包含会话结果、有效观察、运行统计、证据摘要和关注点
五类信息；不应出现评分、排名或能力判断。
