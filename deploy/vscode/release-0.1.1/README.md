# VS Code 编程行为分析插件 0.1.1 交付包

本版新增与 Jupyter 版操作一致的教师端三步方案向导：

1. 在大文本区输入完整题目。
2. 手动添加或生成 AI 知识点建议，然后编辑、删除、排序和复核。
3. 确认题目与观察依据后显式发布，再导出给学生端。

AI 建议不再自动发布。未发布内容会保存为 VS Code 工作区草稿；AI 失败不会丢失输入。HTTP 400 会显示脱敏后的具体原因，只在服务明确不支持 `response_format` 时自动降级重试一次。
