# VS Code 编程行为分析插件 0.1.2 交付包

本版面向学生端完成一次会话的收尾操作：点击“结束、生成简报并导出”后，扩展会先
保存确定性课堂简报，再按学生选择生成可选 AI 建议，最后由学生选择本地目录导出。

- AI 未配置、请求超时或服务失败时，不会阻断简报和导出。
- 导出包始终含有 `analysis_log.json`；AI 建议不可用时会写入安全、可读的状态原因。
- AI 建议中的常见令牌形态和本机绝对路径会在写入前脱敏。
- 学生取消目录选择时，简报和分析结果仍保留在本地，可从“仅导出上次会话”继续。

## 文件

- `behavior-audit-vscode-0.1.2.vsix`：插件安装包。
- `SHA256SUMS`：安装包完整性校验。
- `INSTALL.md`：安装、演示和回滚说明。

本次打包通过 lint、TypeScript 类型检查、129 项单元测试、生产构建、VSIX 内容校验和
本地 VS Code 扩展宿主集成测试。未使用真实 AI 密钥或向外部服务发送学生数据。
