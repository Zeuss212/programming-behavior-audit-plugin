# AI 建议中文输出设计

## 目标

客户可见的 AI 知识点建议与测试建议不得以纯英文内容展示。生成请求明确要求简体中文；模型未遵守时，服务端拒绝该响应，前端沿用现有中文失败提示并允许教师手工填写。

## 方案选择

- 仅修改提示词：改动最小，但模型仍可能忽略要求，不能形成展示保证。
- 提示词加服务端校验（采用）：正常情况直接得到中文；英文响应失败关闭，不进入界面。
- 自动二次翻译或重试：成功率可能更高，但增加演示等待时间、API 成本和不确定性，本轮不采用。

## 范围

- `KNOWLEDGE_SYSTEM_PROMPT` 要求所有自然语言字段使用简体中文；JSON 键、Python 标识符和必要技术术语保持原格式。
- `TEST_SYSTEM_PROMPT` 对测试名称和自然语言说明提出相同要求；测试输入、预期输出允许保留代码、数字和结构化字面量。
- 知识点的 `name`、`description`、`evidence_question`、`support_statement`、`exclusion_statement` 必须至少包含一个中日韩统一表意文字字符。
- 测试建议的 `name` 必须至少包含一个中日韩统一表意文字字符。
- 校验失败抛出既有 `AssessmentAssistantOutputError`，路由继续返回现有中文失败消息，不泄露模型原文。

## 非目标

- 不修改学生行为分析结果的语言策略。
- 不引入翻译服务、重试调用或新依赖。
- 不改变 API 响应结构、前端组件或持久化格式。

## 验收

- 自动化测试证明两个系统提示均明确要求简体中文。
- 自动化测试证明纯英文知识点建议和纯英文测试名称会被拒绝。
- 现有中文建议测试继续通过，完整后端回归不新增失败。
