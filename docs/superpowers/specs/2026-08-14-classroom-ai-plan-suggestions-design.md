# 教师课堂方案 AI 建议设计

**状态：** 已确认设计，待实现

## 目标

在教师创建课堂方案的第一步中，依据教师输入的题目与教学目标生成一份可编辑的课堂标题和知识点建议。AI 只协助起草；教师必须预览、选择使用并可继续修改后，才能按原有流程发布方案。

## 备选方案与决策

1. 在浏览器或教师页面填写 API Key 并直接调用模型。实现快，但会泄露密钥、难以审计且无法统一成本控制，不采用。
2. 复用 Jupyter 插件的 AI 设置。插件只位于学生工作台，教师在发布前尚未进入该工作台，且配置属于用户目录，不采用。
3. 课堂同步服务以管理员 Secret 调用 OpenAI 兼容接口，教师网页只请求课堂 API。密钥不离开服务端、权限与教学流程在同一处校验，采用。

## 用户流程

1. 教师在“课堂方案 → 教学目标与知识点”填写“题目与教学目标”；课堂标题可为空。
2. 点击“AI 生成建议”。按钮在题目为空时禁用，并说明需先填写教学目标。
3. 服务验证该教师是课程教师且拥有该实验，再向已配置的模型请求结构化建议。
4. 网页展示“AI 建议草稿”：建议标题与 1–10 个知识点（名称、说明）。这一步不改写原表单。
5. 教师可点击“使用本次建议”以整体填入标题和知识点，或“继续手动编辑”忽略建议。填入后任何字段均可编辑、增删和发布。
6. 模型未配置、超时、返回格式错误或服务不可用时，页面保留教师已填内容，并展示可理解的错误；手动填写和发布仍可进行。

## 接口与数据契约

新增课堂同步服务接口：

```text
POST /v1/classroom/plan-suggestions
Authorization: Bearer <现有 FinColab 用户令牌>
```

请求：

```json
{
  "space_id": "课程空间 ID",
  "parent_algorithm_id": "教师实验 ID",
  "title": "可为空，最多 200 字",
  "statement": "题目与教学目标，1–10000 字"
}
```

成功响应：

```json
{
  "title": "建议课堂标题，最多 200 字",
  "knowledge_points": [
    {"name": "最多 50 字", "description": "最多 500 字"}
  ]
}
```

服务端对模型响应再次验证：知识点数量 1–10、名称和说明非空且符合上述长度；无效响应统一作为安全错误返回，不交给网页。建议不写入数据库；只有教师发布后的既有计划版本才持久化。

## 服务端配置与边界

课堂同步服务运行时通过 Secret 注入：

```text
CLASSROOM_AI_BASE_URL=https://<管理员配置的 OpenAI 兼容服务地址>
CLASSROOM_AI_MODEL=<管理员配置的模型名>
CLASSROOM_AI_API_KEY=<Secret>
CLASSROOM_AI_TIMEOUT_SECONDS=15
```

- 仅 HTTPS 地址；不支持 URL 中携带用户名、密码、查询参数或片段。
- API Key 不返回网页、不写日志、不进入镜像、Git、前端构建产物或课堂简报。
- 请求使用固定系统提示和长度受限的教师输入；不发送学生日志、票据、对象存储凭据或 FinColab 登录令牌。
- 服务先复用现有 `require_teacher_owner` 校验，再调用模型；未经授权的用户不能消耗 AI 调用。
- 每次调用设置 15 秒超时；调用失败不影响课堂手动流程。

## 前端行为与可访问性

- 生成按钮显示“正在生成…”，防止同一页面重复提交。
- 建议区域以 `aria-live="polite"` 宣布成功或失败；错误不把焦点从教师已有输入中抢走。
- “使用本次建议”是显式操作，避免静默覆盖教师文本。
- 前端不提供 AI Key、Base URL、模型名或原始模型响应展示。

## 测试与验收

服务端：

- 未配置 AI 时，已授权教师得到稳定的“暂未配置”错误；无模型网络请求。
- 非教师、非实验所有者在模型调用前被拒绝。
- 成功响应的长度、数量和字段边界被验证；模型输出无效时拒绝。
- 传输层超时、401/429/5xx、非 JSON 响应不泄露模型内容或密钥。

前端：

- 空教学目标时不能生成；调用参数含当前课程与实验。
- 建议只在教师点击“使用本次建议”后填入；填入后仍能编辑、删除和发布。
- 加载状态禁止重复点击；失败信息可访问且原表单内容保持。

端到端验收：已配置服务后，教师在候选前端生成并使用建议、发布方案；学生按既有 40037 HTTPS 工作台进入并提交；教师查看简报。未配置服务时，教师仍能完全手动发布。

## 非目标

- 不在本阶段让教师上传自己的模型密钥。
- 不自动发布方案、不自动覆盖表单、不对学生日志进行 AI 分析。
- 不改变学生 40037 工作台入口、既有 FinColab 登录、方案版本或简报数据结构。
