# 独立实验考核评价配置设计

## 目标

考核评价配置独立于实验创建内容和课堂发布流程。教师进入某个实验的考核评价页后，可以直接创建、读取和修改行为监测范围与 AI 评价维度；实验文件、开放时间、参与范围、课堂方案是否发布均不得阻塞该页面。

## 绑定与隔离

- 用户界面以实验名称说明当前绑定对象。
- 服务端以 `space_id + parent_algorithm_id` 作为稳定隔离键，同时保存 `experiment_name` 快照，避免不同课程同名实验串数据。
- 实验名称可随配置更新，但不能仅依赖全局名称作为数据库唯一键。

## 数据与接口

- 新增独立实验评价配置表，保存监测开关、评价维度、配置修订号、教师和实验名称。
- `POST /v1/classroom/experiments/{space_id}/{parent_algorithm_id}/assessment-config` 获取或初始化默认配置。
- `PUT` 同路径使用乐观锁保存配置。
- 旧的草稿级评价配置保留；迁移时按草稿实验范围回填独立配置，历史已发布版本不变。
- 后续课堂方案发布时，优先快照同实验的独立评价配置，保证课堂执行可复现。

## 前端

- 考核评价页面始终显示独立编辑器，不再以课堂方案绑定是否存在作为前置条件。
- 页面仅展示实验名称和可选的课堂发布状态；不显示补发时间、参与范围或文件上传表单。
- 保存只更新独立评价配置，停留当前页面并显示成功反馈，不创建课堂版本、不同步学生、不跳转监控页。

## 错误处理与验收

- 非所有者返回 403；配置版本冲突返回 409；字段或总权重非法返回 422。
- 同一实验首次进入自动得到默认配置，再次进入恢复已保存内容。
- 没有课堂方案的已创建实验也必须展示完整评价表单并可保存。
- 后端测试、静态检查、类型检查及前端全量测试、类型检查、生产构建全部通过。
