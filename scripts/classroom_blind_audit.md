# 课堂平台盲审操作单

本操作单用于一次**测试课程**的人工验收。执行者只能根据教师端、学生端和 Jupyter
页面的可见文字操作；不读取源代码、开发文档、数据库、对象存储或浏览器开发者工具。
所有记录使用合成姓名、合成作业与测试课程，不输入真实 API Key、学生作品或隐私数据。

## 角色与开始条件

| 角色 | 职责 | 不可代替的观察点 |
| --- | --- | --- |
| 教师 | 发布方案、结束课程、查看简报 | 方案是否只在教师端出现、简报是否能指出掌握与问题 |
| 学生 A | 接受任务、开始监控、误关恢复、手动提交 | 是否回到同一会话、是否只提交一份简报 |
| 学生 B | 接受任务、开始监控、不手动提交 | 课程结束后 **15 分钟** 是否自动收口 |
| 观察员 | 计时、记录屏幕文字和阻塞 | 不协助点击、不解释隐藏实现 |

开始前由观察员确认：

- 测试课程已进入 allowlist，生产课程未开启；
- 教师、学生 A、学生 B 使用彼此独立的测试账号；
- 两名学生的工作台入口均由 BAMS HTTPS **40037** 打开，不使用 40002；
- 可记录课堂开始、实际下课、+15 分钟、简报出现的时间；
- 已知当前版本、镜像 digest、测试课程标识和回滚负责人，并填入验收模板。

若页面没有教师方案入口、学生不能看到任务、或 40037 以外的地址被要求打开，立即
停止并记为阻塞；不要尝试修改 URL、端口、容器或数据库绕过页面。

## 流程 A：教师发布与学生接受

1. 教师在测试课程中创建一份带至少一个知识点的方案并发布。
2. 教师确认任务同步后仅显示在两名测试学生的任务列表中。
3. 学生 A 和学生 B 各自在自己的页面接受同一节课任务。
4. 观察员记录每一步可见的状态文字、时间和任何无法理解的提示。

通过条件：学生端没有“创建/编辑/发布方案”入口；教师端能看到方案已发布和学生
任务状态。跨课程或非成员账号应得到明确拒绝而非空白页面。

## 流程 B：学生 A 误关恢复与手动简报

1. 学生 A 通过 BAMS 的 40037 打开工作台并开始监控。
2. 学生 A 完成一次合成编辑和运行，确认页面显示最后同步或监控中。
3. 直接关闭该工作台页面（不清除浏览器数据、不重置容器）。
4. 重新从学生端任务入口打开 40037 工作台，确认恢复提示与监控状态。
5. 学生 A 选择“结束并提交”，等待得到提交结果。
6. 教师刷新或轮询课堂页，确认只出现一份学生 A 简报。

通过条件：恢复后是原会话而非新会话；手动提交后不会生成第二份简报；简报显示
知识点、可确认的表现、待改进问题和教师建议。

## 流程 C：学生 B 自动收口

1. 学生 B 通过 40037 开始监控并完成一次合成编辑和运行。
2. 学生 B 关闭工作台页面，不进行手动提交。
3. 教师在测试课程页面执行实际下课；观察员记录实际下课时间。
4. 到实际下课后 14 分钟 59 秒，确认学生 B 仍未显示最终简报。
5. 到实际下课后 15 分钟，教师刷新或轮询状态，确认学生 B 出现自动生成的 completed
   或 partial 简报。

通过条件：自动简报的提交原因是系统截止；缺失证据时简报必须标记 partial 或说明
缺口，不能把未观察到的内容描述为已掌握。

## 流程 D：教师复核与证据下钻

1. 教师打开学生 A 和学生 B 的简报，逐项查看知识点结论、问题和建议。
2. 教师选择一个证据引用尝试下钻原始过程证据，并记录页面反馈。
3. 教师添加一条复核/评语（若页面提供），刷新后确认仍可看到。

当前限制：本地同步服务已有简报与教师复核 API，但教师端页面和原始证据下钻入口尚
未接入本工作树；若没有可见入口，本步骤记录为“产品前置项未完成”，不能以 API 或
开发者工具替代盲审。

## 记录与停止条件

观察员向验收模板记录每项结果、时间、截图/录屏位置（不得含真实令牌）和阻塞文字。
以下任一情况立即停止测试课程的 allowlist，并交由回滚负责人处理：

- 学生能创建、编辑或发布方案；
- 恢复后产生第二个会话或第二份逻辑简报；
- 自动收口超过 15 分钟仍无最终状态；
- 教师跨课程查看数据成功，或无成员账号未被拒绝；
- 40037 正常工作台入口出现回归；
- 简报或页面泄露明文票据、令牌、API Key 或完整学生代码。
